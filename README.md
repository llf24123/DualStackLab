# DualStackLab 0.6.13

Android 双窗口文件管理与 APK 学习研究工具。最低 Android 8.0（API 26），目标 API 36。界面参考 MT 管理器的双列表、路径栏和底部操作栏。

0.6.13 增加 RAR/RAR5 双窗口浏览、只读文件查看及解压；RAR 内的增删改不提供，需先解压。Junrar 许可见 `third_party/licenses/JUNRAR-LICENSE.txt`，测试样例说明见 `app/src/androidTest/assets/rar-fixtures/README.md`。

## 已实现

- 内部存储支持继续逐级上跳：`/storage/emulated/0` → `/storage/emulated` → `/storage` → `/`。列表 `..` 与系统返回使用相同父目录逻辑，自动 ROOT 返回也保留实际路径；`/sdcard`、`/storage/self/primary` 和首页末尾的 `/.` 统一识别。已有 ROOT 时自动读取存储容器；没有 ROOT 且系统不允许枚举时，仅提供已知内部存储入口，其他不可读路径仍报告实际错误。
- 底栏最后一项改为“同步另一窗口”，让对侧定位到当前活动窗口目录，保留活动侧、独立历史和滚动位置；支持左右双向、ROOT 和 ZIP 包内子目录，相同目录不重复压入历史。列表 `..` 与系统返回继续用于上一级。
- Android/data 浏览复用专门的 ROOT 只读目录通道，保留全局挂载视图；空闲 15 秒关闭，最长 30 秒重新创建，错误时关闭并显示实际错误。脚本与 PTY 仍使用独立执行通道。目录读取使用独立双线程队列，过期排队请求取消，慢任务结果不能覆盖新目录。
- ELF 统一为一个执行入口，移除原文件/临时副本选择。ROOT 下优先由内核执行原路径，保留 `argv[0]`、`/proc/self/exe`、`AT_EXECFN` 和原目录；缺少执行位时只增加所有者执行权限。原路径受 noexec 或实际执行权限限制时自动使用暂存位置；原生 exec 失败会恢复本次增加的执行位，目标程序开始运行后的任何退出码都不会触发重复执行。普通模式始终在暂存位置执行，Android 10+ 继续使用系统 linker；Android 8/9 的普通模式也不再尝试原路径。保留 ROOT 开关及文本脚本的普通/管道执行选择，不注入 LD_LIBRARY_PATH。
- 多选删除合并 ROOT 命令并按转义后长度分批，极深且包含大量引号的单路径使用临时命令文件，避免超过系统参数限制。普通目录直接遍历删除，不为删除执行显示排序；不跟随目录符号链接。相同 ZIP 中多项删除只重建一次。删除失败也刷新两窗，所选关键根目录在任何删除开始前统一检查。
- 文件内容为 ELF 时，即使扩展名为 `.sh`，也不会转码或按文本送入管道；已保存的脚本管道偏好不再屏蔽 ELF 的键盘和标准输入。仅通过静态分析检查用户的 ARM64 文件，没有修改或执行其清理和标识重置操作；该文件的保护提示仍需 ARM64 实机复核。
- 外部应用通过文件提供方打开/分享文件时，优先读取已授权描述符的真实路径，并核对设备号和 inode，再跳到原目录选中文件；其他应用私有目录在可用 ROOT 下定位。取消自动另存到接收目录。云端或管道文件没有可访问的实际目录时直接保留原 URI 打开，归档浏览可能使用临时缓存，不生成持久接收副本。
- 长按文件/文件夹 → 属性，显示 UID、GID 和权限，支持所有者/用户组/其他人的读、写、执行九项勾选，以及 Set UID、Set GID、Sticky。八进制输入与勾选同步，支持 600、644、755、1755 等 3–4 位权限，拒绝 900 等含 8/9 的无效值；保存后读回验证。默认只改本项，符号链接和非 POSIX 来源不直接修改。
- 同一文件系统移动直接重命名目录项，保留 inode、内容和权限；ROOT 本地移动使用系统 mv。跨文件系统/SAF 复制回退直接流式写入新目标，移除“源 → 整份缓存 → 再复制到目标”的多次读写。已有文件仍同名避让，移动到原父目录无操作，应用内编辑保留原子写入。
- 压缩包长按操作菜单显示“解压”，支持 ZIP/JAR/APK/APK.1/APKS/XAPK 全包解压、包内单文件/文件夹/多项解压，并可在归档更多菜单选择“解压当前目录”。默认输出到另一窗的新文件夹，可输入目标路径和文件夹名称；同名自动避让，成功后右/左目标窗定位输出文件夹。损坏包或越界路径失败后清理新建输出，不覆盖原文件。

- `.sh` 和 ELF 使用流式暂存，取消原有脚本 4 MiB / ELF 256 MiB 固定上限；编码转换与换行规范化分块处理，大文件不再整体读入内存。暂存空间不足或文件读取失败时报告实际错误，失败会清理临时文件。
- 左右窗口独立导航、路径跳转、历史记录、窗口交换、拖拽复制或移动。
- 顶部路径长按复制当前窗口的完整目录地址，短按继续路径跳转。
- 已取得 ROOT 授权时，进入 Android/data、Android/obb 及其子目录自动使用 ROOT，支持 /sdcard 和 /storage/self/primary 别名；点击进入、路径跳转、最近/书签恢复和文件创建/复制均使用一致访问方式。
- `/data/user/0`、`/data/data`、`/data/user_de/0` 及其他用户的私有数据入口自动使用 ROOT。对支持 `--mount-master` 的 su，目录枚举、文件读写、Shell 和 PTY 均使用全局挂载视图，修复取得 ROOT 后仍只显示少数应用目录的问题；只探测能力，不会用失败重试重复执行文件修改。旧 su 保留标准参数；本应用原本可读的私有缓存保持普通访问。
- 两侧目录之间绘制向左渐淡的 5dp 轻微阴影，适配浅色/深色主题；阴影没有独立触摸区域，不占面板宽度。继续关闭中间拖动划条和列表快速滚动条。
- 文件和文件夹向左或向右侧滑可切换选择；横向起手后继续上下划过可连续选择或取消选择，靠近列表上下边缘会自动滚动。两窗独立选择，底栏提供批量复制、移动、删除及更多操作；“上级目录”不参与选择。
- 目录切换取消整列平移、淡入与临时硬件图层，切换时停止旧目录的惯性滚动和选择手势，减少旧帧与新目录叠加。加载保留原画面并禁用旧项，超过 120 ms 显示进度；下拉刷新保留转圈反馈。两窗共享最多 24 个目录快照、15 秒有效，ROOT 自动转换使用一致缓存键，返回恢复滚动位置。刷新清除当前目录快照，应用内修改与从编辑器返回清除快照后重新读取。底栏只在选择模式改变时重建，默认排序复用后台结果，减少界面线程工作。
- ROOT 枚举使用批量 stat 代替每项启动 stat；断开的符号链接按链接自身属性显示，不再导致整个根目录读取失败；成功授权缓存 30 秒，目录可读探测只读取首项。
- APK 和 `.apk.1` 点击显示应用信息、签名/加固特征及已安装版本，信息长按复制，安装目录和数据路径可跳转；支持系统安装与 ROOT 静默安装。
- ZIP/JAR/APK/APKS/XAPK 在主双窗口直接浏览，支持包内增删改、目录重命名、文本写回、跨窗导入/解压和嵌套 ZIP；RAR/RAR5 支持双窗口浏览、只读文件查看和解压。返回、首页与最近/书签能恢复归档位置。APKS/XAPK 当前提供浏览，不提供 split 安装选择器。
- 未识别后缀单击显示三列“打开方式”，长按先显示文件操作菜单，可继续选择“打开方式”；可选择文本、压缩包、图片、音乐、视频、APK、APKS、Linux 脚本、HTML、SVG 和外部应用；多选通过文件图标或网格“选择文件”。
- 左右窗口独立下拉刷新，ZIP 列表下拉刷新可重新读取外部修改后的原文件；下拉和菜单刷新显示转圈，读取完成后直接更新列表。
- 底部操作栏上滑打开“最近 / 书签”，最近目录去重并保留 50 项；书签支持添加、重命名、排序、删除，记录持久保存。
- 左侧抽屉提供根目录、内部存储容量和已安装应用；主题可选浅色、深色或跟随系统。
- 根目录入口在后台检查 su 的实际 UID，确认 UID 0 后使用 ROOT 枚举；系统 toybox find/stat 跟随目录软链接，Shell 默认使用可访问的工作目录。
- 已安装应用采用用户/系统双标签、应用图标列表；支持搜索、排序、刷新和 base/split APK 提取。详情展示包名、版本、大小、签名、加固特征、SDK、目录、安装时间及 UID，长按复制，目录/APK 路径点击跳转到文件窗口。
- 长按文件或文件夹显示两列五行操作菜单：复制/移动、删除/重命名、工具/压缩（归档或包内选择显示解压）、属性/分享、打开方式/添加书签。复制和移动的蓝点支持长按后输入同窗口目标目录；文件夹禁用分享和打开方式，多选禁用单文件操作。图标点击继续用于多选，图标长按继续支持跨窗口拖动。
- 系统返回先关闭操作面板或清除选择，再返回父目录；内部存储首页继续返回上层，仅在文件系统根目录或没有可返回位置时需两秒内连续返回两次才退出。SAF 子目录使用导航记录返回。
- 外部应用的打开/分享文件入口支持跳到原目录并滚动到文件；ZIP 继续在双窗口内浏览。无可访问真实路径时保留来源 URI 直接打开，重复打开同一文件及页面重建保留正确导航。
- 右上角图标菜单提供刷新、搜索、全选、过滤、排序、打开终端、隐藏文件、添加书签、设为首页、交换窗口、设置和退出。隐藏文件开关与两侧独立首页持久保存。
- 文件和目录增删改查、批量复制或移动、排序、属性、同名避让。
- 所有文件访问权限申请、已授权 SAF 目录恢复和可选 ROOT 文件操作；按本轮界面要求移除旧 SAF/权限工具菜单。
- 正则文件名过滤、当前目录递归搜索、共享存储搜索、文本内容搜索。
- Sora 文本编辑器、语法高亮、编码识别或手动选择、正则查找替换、撤销重做。
- 修复短小无 BOM UTF-16/32 配置和脚本的编码识别；自动候选编码检查字节往返，未知旧编码使用 ISO-8859-1 逐字节保留并标注“推测”，仍可手动选择读取/保存编码。分页仅保留合法未完成字符，非法尾部不会被直接丢弃。
- 编辑文本不再因含 NUL 等控制字符而直接拒绝打开；保留并显示控制字符，支持零字节填充的 UTF-8、UTF-16/32 配置。自动读取遇到损坏的 BOM 或混合字节内容时退回逐字节保留模式，状态栏标记“推测”；保存不会自动删除 NUL、替换非法字节或丢弃二进制尾部。文件后缀不等于内容编码，实际加密或压缩内容仍需对应的解析方式。
- 普通文本超过 2 MiB 时按约 256 KiB 分段编辑，流式保存其他内容；XML、ARSC 和单类 Smali 完整编辑上限为 32 MiB。
- ISO-2022 等有状态编码的大文件通过临时 UTF-8 副本分页，保存时连续转回原编码。
- ZIP 包内文件增删改、导入、替换、重命名、选项解压和目录压缩。
- APK Manifest 与二进制 XML 文本编辑、ARSC JSON 编辑、资源替换。
- DEX 类浏览、Smali 反汇编与回编译、单类编辑写回。
- APK 对齐、签名验证、生成签名 APK、修改包名生成共存 APK。
- 已安装应用的 base/split APK 提取、Shell 命令、`.sh` 文件和 Android ELF 可执行文件执行。
- Shell 支持实时 stdout/stderr、工作目录、stdin/EOF、非零退出码、停止进程组、超时、完整输出日志，以及 BOM/CRLF 脚本规范化。
- ROOT Shell 启动独立子进程组并等待真实命令完成，保留标准输入和退出码；修复 Magisk 环境下 setsid 提前返回导致输出截断的问题。
- `.sh` 点击弹出“设置 / 编辑 / 执行”，设置保存 ROOT 和普通/管道执行选择；执行自动运行。管道方式保留 `$0`、参数及工作目录，但不能追加标准输入。
- `.sh` 和 ELF 执行使用独立黑色 PTY 终端，支持 ANSI/VT 显示、中文输入、点输出区打开输入法，以及 Esc、Tab、Ctrl、Alt、方向键、Home/End、PgUp/PgDn。进程结束后显示退出码，软键盘和硬件回车均可关闭页面。
- 脚本执行不再要求编辑器自动识别编码：保留未知编码和二进制尾部，文本脚本处理 UTF-8 BOM 与换行；UTF-16/32 脚本转为 UTF-8 暂存，源文件不变。
- 0.6.3 终端默认字号 13sp，输出区支持双指捏合/张开放大缩小（10–30sp），字号持久保存；缩放保留正在运行的 PTY 会话和输入。
- 终端菜单提供执行参数、工作目录、ROOT、重新执行、停止、EOF、复制/粘贴、清屏和输出日志。横竖屏和系统主题切换保留正在运行的进程，停止或关闭时清理子进程和暂存文件。
- ELF 根据文件魔数识别，验证程序头、ABI 和解释器；普通模式支持本机 Android/Bionic 动态 PIE，Android 10+ 通过系统 linker 加载只读暂存文件；静态或非 PIE ELF 提示需要 ROOT。

## 构建

本次验证环境：Windows、JDK 17、系统 Gradle 9.8.1、Android SDK Platform 36、SDK Build Tools 36.1.0、AGP 9.1.1。

项目使用系统 Gradle，没有附带 Gradle Wrapper。依赖首次下载需要联网；仓库地址配置在 `settings.gradle`。

在项目根目录用 PowerShell 执行：

```powershell
# 替换为本机的 Android SDK 目录；已经配置时无需重复设置。
$env:ANDROID_HOME = 'C:\path\to\Android\Sdk'
gradle assembleDebug lintDebug
```

也可以在 Android Studio 中打开项目根目录，由 IDE 配置本机 SDK。源码包不包含 `local.properties`。

生成文件：

```text
app/build/outputs/apk/debug/app-debug.apk
```

这是 debug 构建。自行重建使用本机 debug 签名；若与交付 APK 的签名不同，无法直接覆盖安装。

## 安装与使用

1. 安装 APK 并打开“双栈 Lab”。
2. 点击“开启权限”，在系统设置中允许访问所有文件，返回应用后自动刷新目录。
3. 左上角打开侧边抽屉，进入根目录、内部存储和已安装应用；右上角进入文件操作菜单。“主题切换”在侧边抽屉顶部，默认跟随系统。
4. 点击目标窗口切换活动侧；顶部路径显示活动窗口目录，点击路径可直接跳转。
   已有 su 的设备可在路径跳转对话框勾选“使用 ROOT 访问”；取消勾选可返回普通文件模式。
5. 文件或文件夹侧滑切换选择，横向起手后继续上下划过可连续选择，靠近列表边缘可自动滚动。点击图标也可选择；长按文件打开操作菜单，图标长按支持跨窗口拖动后复制或移动。
6. ZIP 点击后直接进入当前文件窗口；APK/`.apk.1` 弹窗的“查看”进入主窗口浏览，“功能”提供高级编辑与静默安装，“安装”选择系统或 ROOT 方式。APK 修改后需重新签名。“打开方式”不展示字体、DEX、十六进制、签名导入、点九、插件、ARSC、XML选项，已有 APK 高级工具仍可从“功能”进入。
7. 点击 `.sh` 选择“设置 / 编辑 / 执行”；设置中选择 ROOT、普通或管道执行，点击执行后自动进入终端。ELF 只有一个执行入口，自动选择可执行位置；ROOT 下必要时增加原文件的所有者执行位。点击 `.elf` 自动执行；其他文件名的 ELF 可选中文件后从“操作”选择“执行 .sh / ELF”。实际内容为 ELF 时不使用文本管道，仍可交互输入。点终端输出区域或 IM 打开输入法，输入发给正在运行的程序。程序结束后按回车关闭；参数、工作目录和 ROOT 可在右下角菜单“执行设置”中调整并重新执行。文本脚本使用 Android 系统 sh。
8. 从底部操作栏上滑打开最近目录与书签，点击条目跳转到打开面板时的活动窗口；长按条目管理记录。右上角“添加书签”保存当前目录，“设为首页”设置当前侧下次启动的目录。

主界面解压默认输出到另一窗的目录。高级工具生成 APK、解压结果和 DEX 工作区默认保存在共享存储的 `Documents/DualStackLab/`。


## 当前边界

- 八进制权限每位仅接受 0–7，900 无效。共享存储 `/storage/emulated/0` 的 FUSE 模拟权限、只读挂载或 SELinux 可能禁止 chmod；本工具读回校验并报告实际权限，不把无效 chmod 显示为成功。权限只改选中项，不递归、不修改 UID/GID。
- 外部来源为云文件、管道、部分文件区间或系统不允许解析真实描述符时，无法推导实际目录；保留原 URI 打开，不自动持久另存。临时授权失效后需从来源重新打开；浏览 ZIP 或编辑器会按需要使用缓存，修改仍需来源授予写权限。
- 同卷移动使用改名，可显著减少读写；跨卷仍需搬运完整数据，速度取决于存储及提供方。ROOT 系统 mv 最长等待 30 分钟，跨卷过程被中断时可能保留部分源和目标，错误会提示检查，不自动删除其他同名文件。
- RAR/RAR5 仅支持只读浏览、文件查看与解压；加密及需要后续卷的条目会提示，符号链接拒绝解压。单次解压上限 4 GiB，解析字典限制 256 MiB；RAR7、分卷、加密和超大字典包仍需实样验证。ZIP 等格式沿用原有读写能力。ROOT/SAF 目标和包内选中项解压会先临时展开，需要额外空间。

- 只在 API 36.1 模拟器上验证；不同 Android 版本和厂商设备仍需实机检查。
- ROOT 依赖设备已有 `su`。API 36.1 x86_64 模拟器已安装 Magisk 30.6，SELinux 保持 Enforcing；已验证受限目录读取、文件读写与删除、ROOT Shell 和静默安装。厂商设备、ARM 和系统分区写入仍未实测。
- 静默安装需要可用的 ROOT；普通模式使用系统安装确认和“允许安装未知应用”设置。Android 版本、签名不一致、版本降级、包校验或厂商策略可能拒绝安装，错误结果会显示，不自动卸载旧应用。静默命令经 stdin 输送 APK，避免系统安装器无法读取应用私有缓存路径。
- 图片以最大边约 2048 像素采样显示；音乐/视频使用系统解码器。HTML/SVG 为本地预览，关闭脚本、网络和其他本地文件访问；外部 CSS/图片等依赖需使用外部应用。文档预览上限 8 MiB。
- ZIP 修改为原文件写回，需要重建空间；嵌套、ROOT 和 SAF 归档需先暂存再写回。目录缓存最长 15 秒，文件被外部工具修改时可下拉刷新。
- su 不可用时根目录入口回退普通 `/`，不会获得额外权限；其他不可读目录显示具体错误。已安装应用的目录跳转会尝试普通读取，再对不可读路径探测 su。外部应用数据目录不存在或被 SELinux 限制时仍可能无法读取。
- 应用详情的加固状态仅基于归档内文件特征；“未检测到加固特征”不代表排除所有加固方案。签名检查针对 base APK。
- 超大文本的查找替换限当前分段；分段模式保留原编码，不做整文件编码转换。
- 自动编码识别采用 BOM、UTF-8/UTF-16/UTF-32 特征和 juniversalchardet。短文本有歧义时会显示“推测”，可在菜单选择编码重新读取。无法保证无 BOM 的任意短文件一定识别正确。
- 内容搜索只检查指定文本扩展名，每个文件最多读取 2 MiB，最多返回 2000 项。
- ZIP 编辑通过临时文件重建归档，需要额外时间与空间。
- ARSC 使用 JSON 编辑，Smali 按 API 28 工作，不保证新 DEX 特性全部兼容。
- 共存处理修改 Manifest 中的包名等字段；硬编码包名、native 检查、复杂 split 依赖需人工处理。
- 修改 APK 后需要重新签名。工具签名密钥保存在 AndroidKeyStore，卸载应用会丢失该密钥。
- 部分异步工作未实现完整的进程恢复或取消流程。长任务期间应保持应用运行。
- `.sh` / ELF 页面为 PTY/VT 终端；右上角“打开终端”保留原 Shell 命令页面及完整流式日志。普通执行运行于应用 UID，不能自动获得 adb shell 的权限；ROOT 模式依赖已有 su。终端支持常用 ANSI/VT，不包含 SSH、会话后台服务或完整 Linux 用户空间。
- 管道执行占用脚本的标准输入，关闭追加输入控件；需要 `read` 交互的脚本使用普通执行。管道末端 sh 的退出码作为结果，不提供 Bash pipefail 语义。
- ELF 已实测 x86_64 Android 动态 PIE 的普通执行和 ROOT 执行；ARM 和 32 位尚未实机验证。Linux/glibc 程序不能直接当作 Android ELF 执行，ABI、动态库、Android API 和 SELinux 仍会限制运行。不注入 LD_LIBRARY_PATH，不自动部署伴随库。ROOT 自动启动优先原路径，缺少执行位时增加所有者执行权限；启动失败恢复本次权限变化，原文件成功运行后保留该执行位。只读/noexec 挂载及 SELinux 仍有约束。已开始的程序非零退出不会自动重试。普通模式及受限位置的暂存启动与内核原路径 exec 的自身路径有差异，带自身检查的程序可能不兼容；用户 ARM64 样本的保护提示具体触发条件尚未确定，不能认定已解决。
- `.sh` 和 ELF 无固定文件大小上限，需应用私有存储有足够暂存空间；脚本转码或规范化换行时还需转换副本空间，ELF 运行仍受设备可用内存和系统加载器限制。源文件内容不改写；ROOT 下 ELF 的执行位可能按上述规则改变。脚本保留原 `$0`，工作目录默认原目录；SAF 文件的工作目录默认为应用 files，需手动选择可访问的本地目录。bash/Python 等其他解释器和依赖需设备另行提供。含二进制控制字节的脚本保留原始负载，不规范化换行；未知编码执行不会强制转换，其中非 UTF-8 输出仍可能显示替代字符。终端单次运行最长 30 分钟。输入在后台按顺序写入，待发送数据最多 1 MiB，超限整次输入会被拒绝。主进程退出后首次空闲读取会结束会话；脱离父进程并延迟输出的后台子进程不保证保留后续内容。
- Shell 页面保留最近约 16 KiB 输出，完整 UTF-8 日志保存在应用私有 files 目录，可从工具栏打开。日志占用磁盘空间；卸载会清除。
- PTY 终端保留最近 10000 行；进程结束时保存当前终端回滚区快照，菜单可打开。该快照保留可见文字，不是无上限原始 stdout/stderr 日志；清屏、VT 全屏重绘和超出回滚区的历史可能不在快照中。
- 有状态编码分页保存会重新编码整个文件，时间与磁盘开销随文件大小增加；字节布局可能规范化，但文本内容和原编码保留。
- 语法高亮处理每行前 4096 个字符，超长行后部仍可编辑，以避免分析器卡住。
